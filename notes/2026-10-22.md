## 卡在
1. **`git config --global` 报 `could not lock config file D:/cadence/Cadence/SPB_Data/.gitconfig`**
   原因：Cadence 把用户环境变量 `HOME` 改成了 `D:\cadence\Cadence\SPB_Data`，而该目录不存在，git 找 `~/.gitconfig` 直接失败。
   解决：不动 `HOME`（怕影响 Cadence），改设 `GIT_CONFIG_GLOBAL = C:\Users\cn06\.gitconfig`，git 单独走这条路。
2. **漏了 `cd`，`git init` 建到了家目录 `C:\Users\cn06`**
   原因：`git init` 认当前目录，不认「我以为的目录」，成功时也不会提示位置不对。
   解决：删掉误建的 `.git`（确认 0 提交后才删）。教训：敲 git 前三件事——看提示符路径。
3. **旧终端里 `python` 指向 Microsoft Store 空壳（0 字节）**
   原因：PATH 是 11:05 才修好的，11:05 之前开的终端读不到新 PATH。
   解决：关掉重开终端；`where.exe python` 现在第一行是 `D:\Python\python.exe`。
4. **`minimum = min(minimum)` → `TypeError: 'int' object is not iterable`**
   原因：`min()` 要一个可迭代对象（列表），传了单个数字 0。
   解决：改成 `min(numbers)`，和 `max(numbers)` 对称。
5. **直接点 ▶ 运行 baseline.py，在第 10 个输入处按回车 → `ValueError: could not convert string to float: ''`**
   原因：程序在等数据，不是等回车；`input()` 拿到空字符串。
   解决：用 `python tools\check.py` 跑，自动喂 10 个数。顺带学会从下往上读 traceback。
