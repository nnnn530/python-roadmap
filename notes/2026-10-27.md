## 卡点（3 个）

1. **推导式变量名不闭环**
   `return [c for w in range(1, n + 1) if c % 2 == 0]` → `NameError: name 'c' is not defined`。
   抄了 `clean_words` 的形状，却没换变量名。正确是 `[i * i for i in range(...) if i % 2 == 0]`。
   教训：推导式三处（表达式 / for / if）引用的必须是同一个变量。

2. **`slow = 0, fast = 0` → SyntaxError**
   逗号是「多重赋值」，不是语句分隔符。一行写两句要用分号 `;`，或者干脆写两行。
   其它合法写法：`slow = fast = 0`、`slow, fast = 0, 0`。

3. **断言期望值写错，冤枉了正确的实现**
   `assert top_words("a b a c a", 2) == [('a', 3), ('c', 2)]` 报错 —— 但 `c` 只出现 1 次，
   Top2 应该是 `[('a',3), ('b',1)]`。错的是期望值。
   教训：写断言前先手算，或先 `print` 出真实数据；平局顺序别写进断言。

## 概念收获

- **变量是便签，不是盒子**：`b = a` 是同一张便签贴同一个柜子（`is` 为 True）；
  `c = a[:]` 才造新柜子。`==` 比内容，`is` 比身份。
- **浅拷贝**：`a[:]` 只复制外层，嵌套的内层列表仍共享；要彻底独立用 `copy.deepcopy`。
- **函数传参同理**：`lst.append(...)` 改原对象；`lst = ...` 只改本地便签。
  这就是 LC 88 必须写 `nums1[:] = ...` 而不是 `nums1 = ...` 的原因。
- **就地修改返回 None 的一族**：append / extend / insert / remove / sort / reverse；
  `pop` 是唯一例外（既删又返回元素）。`L = L.sort()` 会让 `L` 变 None。
- **`range(len(L))` 的毛病**：长度在循环开始时定死，边遍历边删会错位/越界/静默漏删。
  只读用 `for x in L` / `enumerate`；要删用倒序 range 或推导式重建。
- **`enumerate(seq, start)` 的第二个参数是起始编号**，不是取第几个元素；
  返回 `(编号, 元素)`，顺序不能反。
- **推导式的两种 if**：`for` 后面的 if 是过滤（不留 else）；`for` 前面的是三元改写（必须有 else）。
- **能用 ≠ 该这么写**：v2 初版靠「`[slow, fast)` 全是 0」这个没写出来的不变量才成立，
  能过 3000 组压测但难读；改成标准 5 行版后才适合面试。
