## 加练：递归（22:00 补）

- `sum_list`：`if not nums: return 0` + `nums[0] + sum_list(nums[1:])`
- `factorial`：`if n <= 1: return 1` + `n * factorial(n - 1)`
- `count_down` / `count_up`：唯一差别是 `print(n)` 放在递归前还是后，输出顺序整个反过来
- 想通的一句话：**递归调用要等它自己执行完，后面的代码才轮得到** → 栈是 LIFO，所以内层先返回、先打印
- 和循环的取舍：可以用循环就用循环；一旦是「树 / 回溯 / 分治」这种结构，循环写不出来，只能用递归
